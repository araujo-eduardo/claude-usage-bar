# Changelog

## 0.1.0 — 2026-11-11

First release.

- Status line: 5-hour window with reset time, weekly window, context fill and session cost, updated on `session.measure`.
- `/usage-bar` pane: limit bars colored by usage (70% / 90%), context and cost, and a 7-day token history with a per-model breakdown.
- Toast once per 5-hour window past 90%.
- `language` option: `auto`, `en`, `pt-BR`.
